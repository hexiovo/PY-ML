# 从结果文件夹生成 APA 报告

本文件是 PYML 技能的报告工作流，不代表已有程序具备报告按钮。用户在分析结束后给出结果文件夹并要求整理报告时，直接检查该目录及已有实验设计材料，完成有引用的中文 APA 报告；不得只给提纲或让用户自行填结果。仅修改技能时，不顺带重跑分析或宣称报告已生成。

## 入口、运行选择与证据

1. 接收用户提供的绝对目录。优先检查目录内的运行清单、配置、数据字典、实验设计、统计计划、结果、诊断、错误与 PASS 状态；递归检查应有范围与文件大小限制，不为写报告重载全部大型原始产物。
2. 若输入是输出根目录，先核实 latest-run.json 指向的运行及其真实完成状态；不得因存在指针就认定分析完成。多轮结果不得拼接，未完成的新轮不得静默替换成历史成功轮。能由上下文唯一确定时直接选择并注明，否则询问需要报告哪一轮。
3. 将实际执行、未执行、失败、合成夹具和真实数据分别核对。PASS 只证明相应程序检查通过，不是研究假设成立、模型收敛、统计显著或预测有效的证据。缺失阶段与 false 均不得当作成功结果。
4. 从已有对话、设计文件和有效配置建立“研究问题/假设—设计与独立单位—变量/条件—分析方法—输出证据”的对应表。优先复用用户已提供的信息；影响解释的实验设计缺口合并询问一次。等待补充时先整理可核实部分，不从目录名推断招募、条件、任务、随机化、伦理或被试身份。
5. 每个关键数值保留来源路径、文件哈希、字段/表格行定位、分析范围和必要计算说明，另存证据台账。正文使用匿名汇总，不暴露本机路径或参与者标识。涉及原始行的重新计算须明确其范围，报告请求本身不授权重新选模、改统计方案或执行最终 test。

## 内容必须围绕实验设计

正文至少包括标题、方法、结果、简短讨论和参考文献；用户或投稿要求需要摘要等其他部分时补充。必须设置有实质内容的子章节，算法说明须服务于本实验和实际运行范围，不能写成脱离数据的算法百科或软件运行日志。

- **方法**：按真实材料交代研究设计、研究问题或已有假设、参与者与有效独立单位、纳入排除、材料/任务及程序、条件/时间/重复测量结构、测量与特征来源、数据质量和缺失处理、训练/验证/测试划分、预处理拟合范围、模型与参数选择、统计方法及软件版本。只写实际采用的方法；计划、探索性修改和已执行步骤分开说明。未知招募、人口学或伦理信息不能补写成事实。
- **结果**：依研究问题与预设对比组织，先说明实际样本流失和可用数据，再报告描述量及相应预测或推断结果。样本数必须区分参与者、记录、片段、窗口和重复运行；每个结果注明有效样本与分析范围。仅在已有有效输出支持时报告统计量、自由度、效应量及定义、置信区间与区间方法、精确 p 值及多重比较处理。通常报告精确 p，小于 .001 时写 p < .001，不写 p = .000；保留原始精度并统一展示舍入。不可凭均值、fold 波动或 PASS 数编造显著性、置信区间或效应量。缺失/不可估计量标明原因。
- **简短讨论**：通常用 2–4 个实质段落，直接回答研究问题，将实际发现与相关文献联系，说明与本设计有关的解释边界、限制和必要后续验证。不把预测关联写成因果、不把不显著写成等效、不将全量无监督拟合写成泛化证据。没有研究结果时明确当前不能回答哪些问题。
- **当前全方法接口测试的特别边界**：获准的 SYNTHETIC 标签、组和时间仅属于独立测试夹具；每方法 10 次是工程重复，不是 10 名被试或 10 个独立实验。若目录只有这类输出，报告应明确命名为“接口验证报告”，仍按方法、结果、简短讨论组织；说明它支持后续实验流程的哪些环节，不能写成真实 EEG 条件效应、预测性能排名或科研验证。真实数据部分只描述实际使用且有证据的内容。

## 子章节与算法差异（必须）

采用 APA 标题层级形成清晰的主章节和子章节；下列结构为默认内容框架，可按实验调整，不机械保留不适用或没有证据的空章节。标题是否编号服从用户/投稿规范，不把中文论文的数字编号视为 APA 强制要求。

- **方法**下设：研究设计与研究问题；参与者与数据来源；实验任务与测量；数据预处理与特征；算法类别与关键差异；训练、验证与评价方案。
- **结果**下设：样本与数据质量；按研究问题或任务划分的主要结果；可比算法的结果比较；稳定性、诊断与失败情况。接口测试改为覆盖范围、逐方法执行状态、失败与资源记录，不能保留暗示科研性能评估的标题。
- **讨论**下设：主要发现及其与实验设计的关系；算法差异的解释；局限与后续验证。保持简短，每节只写有依据的内容，不为章节数重复扩写。

必须解释本次范围内各个算法的差异，而非只列名称或笼统说“各有优劣”。以实际清单核对覆盖，按分类、回归、聚类、降维、异常检测、序列/时序等任务分组；搜索方法与训练前降维另列，不混作预测器。正文按算法家族解释共同机制和关键分歧；逐算法条目放入比较表或附录，保证范围内每个算法均有对应说明，并保留未执行、失败及不适用状态。

算法比较表至少列出：实际 ID/名称、所属任务、核心机制与假设、输入/输出与标签需求、缩放/分布/序列边界等要求、关键参数及本次取值、可解释性、适用条件与限制、与本实验的关系、实际执行状态和方法引用。尤其说明同家族变体在损失、正则化、核、集成策略或序列假设上的实质差异；用源码/API 和原始文献核实，不能仅凭名称猜测。运行耗时/内存只用实测值，理论计算特点与本次测量分开。

区分“理论机制不同”与“本次结果不同”。只有数据、目标、划分、指标定义和预算可比时才并列比较效果，交代剩余差异；分类与回归指标、不同夹具或不同评价范围不能混排总榜。不得为了丰富差异说明追加拟合或挑最好种子。当前每方法 10 次接口测试应报告已保存的开发集数值、分类输出及特征排序，并解释机制与适用性；这些合成结果不能用于判断真实 EEG 的最佳算法。

## 图表绘制与可复现交付（必须）

报告必须实际绘制并嵌入图和表，不能只写“建议绘图”、留下图位或仅贴 UI 截图。至少包含算法差异比较表、对应研究问题的结果/执行状态表，以及由本轮可核实结果生成的图；数量取决于信息量，避免重复展示同一信息。材料不足时先绘制可核实的运行状态图或数据流程图，并明确科学结果图所缺证据，不编造数据凑图。

- 真实科研结果按任务选择有解释价值的图：设计支持的条件分布/配对变化、估计值与有效区间、冻结预测的混淆矩阵或校准图、回归预测与残差、聚类/降维描述图、真实时序的预测图等。只绘制实际输出支持的图，不把嵌入空间中视觉分离当成统计显著或泛化证明。
- 当前接口验证优先绘制“方法×重复编号”的 PASS/未通过/未提交状态矩阵及按任务汇总的执行状态图；若有真实测量，再绘制耗时或资源图。缺失状态不得填为 false，失败不能被均值隐藏；未记录逐循环耗时不能反推伪造。合成与真实数据分图/分面并在图题或图注明示，禁止绘制暗示科研优劣的模型性能排行榜。
- 每张图表采用 APA 编号、标题与必要注释，在正文中明确引用和解释。标明变量、单位、有效样本、数据分区、真实/合成来源、缩写与聚合方式；误差条注明 SD、SE 或区间及其计算单位/方法，不将重复种子波动当作独立被试区间。显著性标记必须有实际有效检验来源。
- 保持字体、字号、配色和数值精度一致，保证中文正常显示；颜色配合形状/文字区分，兼顾色觉差异及灰度阅读。避免装饰性三维图、误导性坐标裁切和过密标签；算法很多时按任务分页/分面，完整清单放附录，不能只展示成功算法。
- 使用标准绘图工具生成独立文件，并将图表嵌入 Word。保存 figures/ 下的矢量 PDF 或 SVG，以及适合排版的 PNG（默认 300 dpi，按目标规范调整）；保存 tables/ 下的表格数据、figure-data/ 下的绘图汇总数据和可运行的 make_figures.py 或等价脚本。脚本读取冻结结果，不自动训练或调用最终 test；记录环境与必要随机种子，保留匿名化边界。
- 验收时实际查看渲染后的图及 Word 中嵌入效果，检查标签、字体、图例、色标、截断和跨页；逐图核对数据文件、数值范围、计数分母及正文说明。report-check.json 记录图表清单、来源、核验结果与未完成项；绘图脚本成功退出不等于视觉检查通过。

## 预测结果与分类特征排序（必须）

报告的“结果”不能只有PASS、耗时和警告。分类任务必须优先报告已保存的accuracy、balanced accuracy、precision/recall/F1（说明平均方式）、AUC及其定义、混淆矩阵、逐类样本量，并给出分类相关的特征排序；依实际数据和接口确定适用项。科研结果与工程合成夹具结果都应保留真实计算的数值，但标题、表注与图注必须明确数据来源和train/validation/OOF/test范围。合成夹具数值只描述接口输出，不据其选真实EEG的最佳模型或解释脑区作用。

- 一站式程序首次执行就应在独立结果文件中保存每方法/重复的开发集指标、逐行真实值与预测值、连续分数及类别顺序、特征名、解释结果、划分身份、参数、版本和来源；stages.json仍只记录PASS布尔值。会话内指标计算完后直接删除会话且只保留PASS，不能称为完整结果交付。记录未定义指标的空值与具体原因。
- AUC必须来自真实predict_proba或decision_function连续输出，并固定正类及类别顺序。二分类注明正类；多分类说明OvR/OvO与macro/weighted。decision_function可用于ROC-AUC，但不能当概率计算校准、Brier或log loss。仅类别预测、单类别评价集或不支持分数时写明不可估计，不伪造AUC。准确率是与真实标签一致的比例，不能用PASS比例替代。
- 对可比数据与划分提供逐算法指标表及图、适用的ROC/PR曲线和混淆矩阵；同一数据的重复种子结果可作均值、SD与范围描述，不能把10次重复当10个独立实验或给无依据的总体置信区间。禁止只挑最好一轮；固定代表轮或展示全部。算法按预定ID/任务排序，性能排名若涉及科学结论仍须有效设计和独立验证。
- 分类特征排序必须交代定义与范围：树的原生不纯度重要性、线性系数（保留符号并注明标准化/类别）、置换重要性或经核实的其他解释方法不得混称同一种重要性。默认可使用冻结模型在验证集上按原始输入列置换，记录评分函数、置换次数、种子、下降量、负值和变动；不重新训练，也不把解释结果用于回头选特征。相关特征会分摊或遮蔽重要性，低预测效度时排序尤其不稳定，重要性不是因果或显著性。
- 降维后分量的系数/重要性不是原始通道重要性。使用完整已拟合流程对输入列置换可得到输入层面敏感性；仅当有有效映射时才回传，否则明确是分量排序。真实EEG特征名与人工f00等夹具列不得混用，不将合成列映射成真实脑电通道解释。
- 必须专门交代是否进行了降维：方法、输入/输出维数、真实或合成数据、拟合范围、是否用于后续预测，以及只是筛选若干输入列还是实际学习转换。独立降维接口测试通过，不等于所有分类器都使用降维；同时报告降维分量/嵌入未保存等可追溯限制。
- 现有目录缺少指标、预测或模型时先明确“原运行未保存，不能恢复”；用户明确要求补充计算指标/重要性时，可按冻结开发方案另建补充运行并说明新增拟合、数据和预算，保留原运行和PASS。不能把新增计算冒充原始导出；不得重选模型、改变标签含义或调用最终test。若用户仅要求读取报告则不能默默重训；真实标签缺失时不得伪造真实EEG准确率。

## APA 格式与真实引用

- 默认按 APA 第 7 版组织稿件与文内作者—年份引用；有明确期刊/院校要求时按其要求调整并说明。生成时核对 APA 官方格式说明及适用的量化研究报告规范，不能凭空杜撰格式要求。
- 默认交付可编辑的 report.docx，正文具备一致的标题层级、页码、双倍行距、2.54 cm 页边距、适合中文且统一的字体和参考文献悬挂缩进。作者、单位等题名页信息仅使用已知内容；缺失时标明待补，不编造。表格按 APA 编号、标题及表注呈现，避免竖线和重复正文数值；图表按上节要求实际生成、嵌入并核验。不能把只有 Markdown 标题和链接的文件称为完整 APA 排版稿。
- 引用必须支持具体的方法选择、指标解释或讨论观点。优先查证原始方法论文、与实际任务相关的研究及软件正式推荐引用；数量由内容需要决定，不凑篇数，不以通用机器学习文献代替实验范式证据。
- 实际生成报告时通过原始论文、出版社页面、DOI 登记信息或官方文档核实作者、年份、题名、期刊、卷期页码/文章号和 DOI/URL。没有确认存在和支持相应论点的文献不得放入正式参考文献；不能虚构引用、DOI 或页码。只有摘要可读时，不声称读过全文或据此引用无法核实的细节。
- 文内采用 APA 叙述式或括号式引用，末尾按 APA 排列完整参考文献，DOI 使用 https://doi.org/ 形式。核对文内与文末一一对应、同作者同年区分、作者顺序与年份一致；网页链接清单不能替代参考文献。直接引语须有可核实的定位并遵守引用长度限制，默认用准确转述。
- 无法联网或无法核实引用时，仍可整理已核实材料和正文草稿，但明确引用核验未完成；不把搜索片段、AI 记忆或待查文献包装成已查证依据。

## 自然、克制的学术语言

“去 AI 味”指可读、具体、有证据的写作，不承诺规避检测。使用自然的中文学术表达，让每段围绕一个与本实验有关的事实或解释展开，适度变化句式。

删除“随着……发展”“具有重要意义”“综上所述”等无具体信息的套话，以及重复总结、空泛赞扬、机械的首先其次最后和夸张结论。用具体条件、数字、方向与不确定性代替“显著提升”“充分证明”等无依据措辞。统计意义与日常意义区分；不用第一人称虚构亲历，不伪造研究者观点。不得为了文风顺畅删除负结果、失败、关键限制或来源。

## 保存、完成与验收

- 默认保存到所选运行目录下新建的 reports/<时间戳>/，遵守用户另行指定的报告位置；保留源数据、旧报告与 stages.json。报告过程不改写方法的 PASS 状态。
- 交付 report.docx、便于检索的同内容 report.md、evidence.csv（结果来源与设计对应）、references.bib（已核实文献）和 report-check.json（所选运行、输入来源、格式/数值/引用核验、缺失项及完成状态）。这些是报告侧车文件，不是 PYML 原生配置字段。
- 交付前核对正文与表格数值、样本单位/分母、方向、单位、舍入、区间和显著性标记；核对所有引用的存在性与论点支持；检查文档实际排版、表格跨页和标题层级。不能仅以生成文件成功代替验收。
- 实验设计关键资料不足、运行不完整或引用未核验时，可以交付明确标注的草稿/部分报告并列出缺口，不称为完整科研报告。说明实际交付与未完成项；没有 DOCX 生成或排版核验能力时明确限制，不能宣称 APA 排版已完成。
- 后续用户可直接发送“按 PYML skill，把这个结果目录整理为 APA 报告：<目录>”。一键程序的操作说明应告知这一用法；只有实现并验证过的目录输入框/报告按钮才能描述为现有 UI 功能。

## 真实特征与人工目标的独立分支

仅在用户明确要求时建立，不将两种来源混淆：X为真实全部特征，y为显式人工标签。正文、图注、目标字典及每条结果均标记REAL_FEATURES_ARTIFICIAL_TARGET。标签固定，不通过特征阈值或分数反推目标以制造性能；若刻意按特征构造教学目标，必须另外声明循环定义，不能作独立预测证据。按已确认的被试身份分组并保存分区审计；没有确认身份就明确限制，不猜。报告真实数据的原设计资料与人工验证设计分开，只说明人工任务的accuracy/AUC及特征敏感性，不推断真实条件或生理效应。

## 全任务模板结果图验收
