# 转换目录与适用性

本指南帮助判断可能的转换是否适用于当前研究设计。每项都先标为 enabled 或 disabled，写明输入、输出、参数、顺序、单位、行/ID行为、学习范围、可逆性和来源。若不知道数据单位、编码含义或操作定义，先询问；不能靠常见习惯推断。

## 通用转换记录

每个步骤在 preprocessing.plan.json 中至少包含：

- step_id、type、status、rationale、source_or_reference。
- input_columns 与 output_columns；是否改变一行的含义、行数、排序或键。
- 参数和参数单位、是否依赖目标、拟合数据范围以及训练折内重拟合方式。
- 缺失、非法值、非有限值、零值、负值、边界值和失败时的行为。
- 是否可逆、逆变换的规则、近似或不可逆部分。
- ID、组和时间列如何保留；输出如何与原始记录对齐。
- 输入/输出文件 schema、数据类型、行数、哈希及脚本版本。

所有 ID 都作为侧栏追踪信息保留。只有经过明确论证，才将 ID 派生值纳入模型输入。对 reshape、group aggregation、windowing，写出旧行键如何映射到每个新行。

## 文件解码和表格读取

PYML 当前表格读取接受 CSV、XLSX、XLS。CSV 接口目前只有 encoding 参数，默认 utf-8-sig；它没有原生 delimiter、decimal、date parser 等配置。分隔符、引号、编码或小数点不确定时，先只读检查文本开头和列名，确认格式再用独立准备脚本读入。Excel 要明确工作表；缺省使用第一张表。不要把读错列数的 CSV 当作正确数据继续建模。

## Long / wide 与多文件合并

- long：每次测量一行，适合重复测量与试次级记录。需要稳定的参与者、条件、试次、时间和观测列。
- wide：每个单位一行，重复测量值展开为多个列。适用于明确的单位级横向分析，但更改后不再保留直接的测量行。
- 转换前先确认每行含义、ID 唯一性、重复次数、缺项与条件配对。记录 reshape id_vars、value_vars、变量名和取值列。
- 合并前验证主键和预期 cardinality。保存合并前后行数、未匹配键、重复键、唯一 ID 数及已验证关系。禁止没有预期关系的多对多连接。
- 转为 wide 时记录 pivot 是否出现重复 key；不能静默取首个/平均值。
- 转为 long 时记录每个输入列与输出测量类别的映射、单位转换，以及缺失代表未测还是零值。
- 输出新数据文件，保留源文件与来源哈希；在摘要行级别核对 key 值和结果对应关系。

## 单位、时间与编码

- 单位转换仅在原单位和目标单位已知、有来源依据且量纲一致时进行。记录精确的乘数/偏移，例如摄氏度转华氏度的公式；保留原始列和新列。
- 时间转换需要时区、日期格式、夏令时处理、排序稳定性和重复时点策略。PYML time split 在普通表格要求唯一时间值；相同时间需先设计聚合或阻塞。
- 类别码本要保留代码与标签的字典及未知值处理；不能以字母顺序代表有序等级，除非研究量尺确实如此。
- 数字文本转数值要明确千位分隔符、小数点、负号与单位后缀；转换失败列出行和原值，不直接 coercion 成缺失。
- 时区、单位或类别含义不清时停止，不得猜。

## 缺失值和样本/特征筛选

先把真正缺失、检测下限、结构性缺失、拒答、不适用、设备失效和合法零值编码分开。将特殊 sentinel 变成 missing 之前，需来源确认。逐列汇总缺失数与比例，并按组、条件、时间和结果检查分布。策略可以是删除、训练集填补、带缺失指示变量或专门的多重插补，但需按设计选择。

PYML 的普通表格特征处理为：数值缺失用训练行中位数；类别缺失先众数填补再 one-hot；模型折内处理由 PYML 执行。目标缺失会被拒绝。若研究需要特定的多重插补、多层填补、插补不确定性传播或特征缺失机制推断，普通 PYML config 无法表达，单独实现并验证，可能需要在每个CV折重建全部拟合步骤。不能把填补后单一数据集的预测分数当作统计不确定性。

样本筛选条件需含数据来源、条件时点、执行顺序和筛除数量。只按训练数据估计的过滤规则应严格区分于外部资格条件。基于结局筛选、离群值后删样本和事后亚组均要有科学依据。

## 离群值与范围

分开描述录入错误、物理不可能值、临床阈值外、分布尾部观测及高影响值。只有错误/不可能性有独立来源证据时才能纠正或排除。通用 z-score/IQR 阈值不是错误标签。可同时报告保留和排除的敏感性结果，但应预先声明并控制比较家族。以数据估计的剪尾阈值只在训练折内拟合；不得用全表检测并删除测试异常行。

## 量表反向计分与合成

对每个条目记录反向规则与量程上下界。常用线性反向为 new = min + max - old，但只有量表手册确认了编码与范围时才适用。不能将缺失值误变为最高分。量表合成说明允许条目数、缺失条目规则、是否等权、缺失处理、总分单位和是否可用于分类/回归；来源优先使用量表手册/研究计划。

类别身份仅可按量表定义转换。成分分数不能靠缺失值随意平均；若合成必须由合格研究者确认，清楚记录版本和具体条目。

## 缩放、对数、Box-Cox 与 Yeo-Johnson

缩放应服务于模型或解释需求。StandardScaler 按拟合数据均值和标准差；MinMaxScaler 映到范围并可能剪裁；稳健尺度通常基于中位数和分位距。PYML 会按模型在训练子集拟合普通数值缩放，但没有任意用户缩放选择字段。若研究需要指定缩放方法、单位处理或跨特征单位可解释性，应在外部脚本中实现并保持折内拟合。

log 与 Box-Cox 通常要求适合的正值定义域；自然对数的零、负值处理不能默认为加一。若使用位移参数，必须给出来源、常数单位和逆变换公式。Box-Cox 的 lambda 从数据拟合，必须仅用训练部分估计。Yeo-Johnson 可处理带符号数据，但参数仍从数据拟合。记录变换前后范围、零值/负值/缺失值处理、lambda、估计样本范围、逆变换和偏差校正。

目标变量转换需与损失、预测解释、回变换后的指标和预测区间一致。对数尺度预测的简单指数回变换一般不等于原尺度期望。不要把回变换后的预测分数误作原尺度的拟合值。PYML 当前 config 无目标变换字段；使用外部模型/转换脚本时需明确接口并实测。

## 分箱、编码、特征生成

- 分箱边界应有领域依据或仅由训练折估计。闭区间/右闭区间、边界值、不在边界的输入和缺失值都要定义。
- One-hot 类别与目标编码的未知值规则、稀有类别合并条件和训练/测试编码映射要记录。目标编码必须交叉拟合或只在训练折内部生成，不能对同一训练记录直接使用包含其标签的类别均值。
- 交互、比值、差值、平方项、聚合和滞后/差分说明输入列、单位、对零值处理、时序顺序和记录覆盖。比值分母接近零时应按设计停止或设为缺失，不可无提示产生极端数值。
- 滞后和差分在独立时间序列/参与者内部执行，先排序，不能跨 ID 差分；窗口的来源行、目标行和 horizon 要保留。禁止把未来信息加入预测特征。
- 主成分分析是训练输入上估计的转换，不能先在全表拟合再分折。当前 PYML 另提供监督流程内的可选训练前降维：旧字段 `pca_components`，或 `reduction_method` 与 `reduction_components`；原生方法和模型限制见 `references/toolkit-contract.md`。降维器只在当前训练分区或每个 CV 训练折内拟合，验证/测试只应用已拟合的变换。它不同于 standalone `dimensionality reduction` 任务；Standalone 任务用于输出 embedding，不会自动向其他监督任务添加降维。
- SMOTE 等过采样仅在训练折内，且对类别特征需选兼容的变体；保留原样验证/测试分布。记录生成样本的审计状态，不能冒充真实参与者。

## 时间序列信号转表格

在每行对应一个独立窗口/对象时，可从信号提取均值、标准差、范围、频域功率、峰值、斜率或预定生理特征。必须固定采样率、时间基准、窗口长度/步长、滤波器、伪迹规则、缺失处理、边缘窗口、频段/单位及每项特征定义。避免仅用完整记录长度和已知目标长度推断目标标签。

若特征提取依赖全段或全体数据的统计量，应在部署可获得的范围内做，并检查是否提前使用未来信号。按参与者/试次生成窗口时保持来源 ID、原始样本区间、窗口起点、终点和目标 horizon。验证或测试窗口不能与训练窗口发生未经计划的原始信号重叠；重叠窗口还需适当 purge gap。PYML 的普通表格 gap 不会自动完成holdout purge。

## 转换后交付

转换脚本写入新目录并保留原数据。完成后报告输入和输出文件哈希、行数、ID/键对齐、目标分布、数据类型、单位、缺失数、范围、错误记录、变化列、转换版本以及随机种子。使用独立的手算/已知映射小例子校验单位换算、反向计分、分箱边界、滞后和逆变换。缺少可验证预期时标 NOT VERIFIED。
