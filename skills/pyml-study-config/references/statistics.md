# 最终统计设计与执行契约

本文件约束使用技能的 AI 如何把研究问题变成可执行统计步骤。不是让主试从方法菜单自行选检验，也不是当前 PYML 已实现这些检验的声明。以当前源代码和实际环境为准；预测指标、交叉验证均值/标准差不等于推断统计。

## 先固定问题和分析单位

在看效果、排名或 p 值之前，为每个主要和次要假设固定：结局与单位、总体、估计量（例如 B−A 的人均差）、方向、独立/随机化单位、重复/聚类单位、纳入排除、汇总方式、协变量、对比、区间水平、显著性水平和多重比较家族。无预设时可建议双侧、alpha=0.05、95% 区间，并记录 proposed，不能把建议写成用户原有方案。

一个被试有多行不是多个独立被试；试次、窗口、fold、随机种子或同一数据集上的多个模型都不能直接充当独立样本。随机化在班级/设备/家庭等层级发生时，以该层级安排推断。交叉/嵌套结构需写出被试、刺激、会话等键及其关系。聚合改变估计量，须预先规定每人等权还是试次加权、最少有效试次数及缺失条件；禁止为跑通而临时取均值消除依赖。

纯预测研究可明确 `inference.applicable=false` 并说明原因，但仍指定泛化目标、性能指标与适当不确定性估计。实验效应研究不能用预测分数替代所需检验。两种目标兼有时分开结局、数据范围和证据。随机试验中的因果解释还取决于随机化、依从、缺失和分析策略，模型拟合成功不自动提供因果结论。

## 由 AI 选择并论证路线

以下是候选路线及关键适用条件，不是自动按表套用的默认值。方法必须匹配目标估计量及独立性；无法核实软件实现时标 blocked。

| 设计/问题 | 候选路线 | 必须核实的条件与输出 |
|---|---|---|
| 两个独立组、连续结局、目标为均值差 | Welch t 或匹配设计的回归模型 | 独立单位、极端值/样本规模、差值方向、均值差及其区间；若用等方差方法须有依据。SciPy `ttest_ind` 默认等方差，Welch 必须显式 `equal_var=false`。 |
| 同一人两个条件、连续结局 | 配对差分析或重复测量模型 | 通过匿名 ID 和条件键匹配，不能按行号配对；检查差值分布而非分别检查两组；说明完整配对数及缺配原因。 |
| 独立多组/多因素、连续结局 | 合适的 ANOVA/回归、异方差模型或 Welch 路线 | 因素编码、参考水平、交互、对比权重、方差假设、组数与每组独立单位数。事后比较使用预先声明的家族。 |
| 多条件重复、混合组间组内、嵌套/交叉数据 | 重复测量 ANOVA、线性混合模型或 GEE 等 | 方差/相关结构、随机截距/斜率、缺失机制、模型可识别性；ANOVA 路线考虑球形性及适用修正，混合路线检查收敛和奇异性。不能以普通独立组检验替换。 |
| 有序/重尾结局且秩问题符合研究目的 | Mann–Whitney、Wilcoxon、Kruskal–Wallis、Friedman 等 | 保持独立/配对/区组结构；秩检验通常不直接等于均值或中位数检验。Wilcoxon 要考虑差分的对称性、零差和 ties 的处理。 |
| 二元/比例/计数 | 合适的列联检验、配对二元检验、二项/Poisson/负二项模型等 | 成功数与分母/暴露时间、稀疏单元、过度离散、重复/聚类结构、效应尺度（风险差、比值比、率比等）。不能将比例当无界连续数直接套模型。 |
| 相关、协变量调整或解释性回归 | Pearson/Spearman/偏相关、线性/广义线性模型等 | 目标关联、变量尺度、独立性、线性/单调性、残差、异方差、共线性、交互和多重比较；预测算法特征重要性不是回归系数显著性。 |
| 生存、复杂时序、多变量或贝叶斯问题 | 设计匹配的专门模型 | 先取得执行器接口和数据契约，指定删失、时间相关或先验等；本技能不承诺 PYML 原生支持。 |

不能仅凭一次正态性检验 p<0.05 自动换非参数方法；不能在多种方法中挑显著者。诊断应结合设计、估计量、残差/配对差、影响点和样本规模。记录一个主方法及有科学理由的预设敏感性分析；诊断不满足且无预案时保留失败证据、说明修订及探索性状态。

## 模型性能比较和不确定性

- 比较须使用相同数据身份、相同分区、相同指标定义和独立单位，并通过原始 ID 对齐预测。模型在同一个人的测试数据上产生的预测是配对的。
- 同一数据的 folds、重复 CV、随机种子存在依赖；禁止把 k 个 fold 分数直接当 k 个独立样本做普通 t 检验。CV 标准差是分折变动的描述，不是总体标准误或置信区间。
- Bootstrap 的抽样层级匹配独立单位：重复数据按整被试/集群重采样，时序采用有依据的块策略；明确成对重采样、多层抽样、次数、种子、区间方法和失败处理。对冻结测试预测重采样反映固定模型的条件不确定性；若要包含训练/选模不确定性，需要在重采样内重做相应训练流程并单独授权、预算及验证。
- Permutation 明确原假设、可交换单位和受限交换规则；需在置换内重跑的预处理/选特征/调参不能省略。不能把重复测量的单行自由打乱。Monte Carlo p 值写明计算方式、次数与最小分辨率，不把有限置换输出写成 p=0。
- 多模型选择只用训练/开发数据。PYML 的 holdout test 只用于冻结后的最终评估；bootstrap 读取已冻结预测不会授权重新训练或重测。最终测试失败不得用新建 job 或改种子恢复“再试一次”。已看测试后改变方案要明确测试污染和新的独立验证需求。
- 仅有一张排行榜的均值，且缺逐独立单位预测、外部数据集或有效比较设计时，可描述分数差；不能编造性能显著性。概率指标还需真实概率、正确正类、类别顺序及相应校准策略；不把 decision score 当概率。

## 缺失、转换、剔除与多重比较

预测用训练折内插补不能自动替代推断的缺失处理。统计计划说明完整案例/配对删除/多重插补/模型直接处理等选择、假设和敏感性分析；多重插补需实际合并估计与方差，不能平均 p 值。报告每个结局的有效人数、配对数/集群数与删除原因。目标列缺失在 PYML 监督训练会被拒绝，不能静默用预测填标签。

对数/幂变换后的检验须说明效应尺度、变换参数来源及回译规则。反变换的均值通常不等于原尺度均值；预测反变换的偏差修正需单独依据。不要把变换尺度区间直接贴上原单位。定义域错误、不足样本、全常数、全零差、类别缺失、完全分离和不可估计效应均输出明确状态，不强行加噪声或任意常数。

提前给每个假设分配 `family_id`，记录家族全部假设 ID、校正方法和预定比较数。控制家族错误率可采用有依据的 Holm 等方法；探索性 FDR 路线须说明其控制目标。不能把所有修正统称“校正 p 值”而省略具体方法；BH 路线还需考虑依赖条件。主要/次要/敏感性分析不能事后为了好看拆家族。某个检验失败时保持原家族及失败项，按预定策略处理；不把剩下成功项重新定义为较小家族。单侧选择必须事先有方向依据，不把双侧 p 简单除二作为事后操作。

## 下游 AI 必须生成的统计执行包

**这些是本技能的侧车约定，不是 ExperimentConfig 原生字段，也不是 PYML 自带统计执行器。** 需要统计时下游 AI 创建并核实以下文件：

1. `statistics.plan.json`：严格 JSON。至少含 `schema_version`、`applicable`、数据路径和内容哈希、分析单位/配对键、结局与单位、因素/协变量及水平编码、假设与对比方向、模型/方法和所有有效参数、缺失/排除/聚合策略、诊断与失败处理、alpha/区间方法、family 定义与校正规则、随机种子/重采样设置、依赖实际版本、输入输出表契约。
2. `run_statistics.py`（或用户已有环境的等价脚本）：仅实现当前设计确需的方法。显式解析侧车契约，不把它传给 `ExperimentConfig.from_dict`。用可复核的现有统计库，核对版本/API、参数和返回值；保持原始数据只读，输出到新目录，入口核实键、水平、样本单位及有限值。无实现不能仅留 `TODO` 却授予 ready。
3. `statistics-input.csv`/相应表：保留匿名 ID、条件/组、会话/聚类、结局、单位和有效性/排除字段；预设过滤或聚合产生该表，记录与原行映射。一行代表什么须明确，禁止把训练行与测试行混成一个效应表。
4. `statistics-results.csv`：每行一个预设假设/对比，列至少含 hypothesis_id、family_id、method、contrast、estimand、estimate、effect_size_definition、effect_size、ci_lower、ci_upper、ci_level、ci_method、statistic、df（如适用）、p_raw、p_adjusted、correction_method、n_independent、n_rows、n_pairs/clusters（如适用）、status、reason。未估计量用空值加原因，不能伪填 0、1 或“无显著差异”。
5. `diagnostics.json`、`exclusions.csv`、`统计说明.md`、`verification/`：保存诊断、收敛/奇异性、样本流失、执行命令/退出码、版本及输入输出哈希、模拟例子和实际试跑证据。报告估计、区间、效应量定义、精确 p、有效样本及局限，不把 p>alpha 当作等效或“完全没有效应”。

纯预测分支可只生成 `statistics.plan.json` 的 `applicable=false`、原因及性能不确定性方案，不创建伪统计结果。若涉及等效/非劣效，必须事先给有意义的界值并使用相应检验，不能靠“不显著”达成。

## 最少充分验证与状态

先做一个有可计算预期的小型合成例子，核对配对键/方向/独立人数/估计量与区间尺度、多重比较家族及失败状态；用可信库结果、手算简单均值差或不变量作为依据，不能仅确认脚本退出0。有真实材料再用保留完整条件/配对/集群结构的代表性小样本试跑。已通过且未受影响的证据复用，不在每层/每轮全量检查。

方法或依赖缺失时标 blocked，向主试说明所缺事实/软件和最短下一步；允许交付完整草案，但不能换检验以绕过能力缺口。真实输入未验证时最高只能是 pending_real_data；统计脚本执行成功也不自动证明设计正确。只有整个所需链条均有对应证据，才可能 ready_for_execution。completed 还要求任务包含真实执行且结果验收通过。
