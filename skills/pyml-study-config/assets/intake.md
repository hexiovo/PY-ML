# 实验设计 intake 表

请由主试或研究人员填写自己知道的事实。不要为填写表格而猜测；不知道时写“缺失”，让助手集中提出会改变数据含义、划分或统计结论的问题。可以直接用原始描述回答，不需要先掌握统计术语。

## 研究目的

- 研究问题或实际决策：
- 主要结果或预测目标：名称、定义、允许取值、单位：
- 主要比较、预期方向或确认性假设：
- 预测用途：用于什么对象、什么时间点、部署时哪些信息可用：
- 这次是预测、描述、因果/组间推断、方法比较，还是混合目标：

## 数据来源与行的含义

- 文件位置、格式、工作表；如有多个文件请分别列出：
- 一行代表什么：一个人、一次访问、一次试次、一段时间、一个设备读数或其他：
- 同一参与者/地点/班级/设备是否多行；标识列名：
- 时间/顺序列名、格式、时区、单位；是否有相同时间戳：
- 数据是 long（每次测量一行）还是 wide（每次测量分列）；未知时附列名样例：
- 数据如何匹配/合并；每个表的键以及预期关系（1:1、1:多、多:1）；重复键是否允许：
- 原始文件编码、分隔符、小数点符号或其他区域设置：
- 允许保留的原始列；绝不能作为预测输入的列：

角色可写：目标、预测特征、参与者/分组标识、时间/顺序、排除列、独立参考标签、追踪字段。

## 数据纳入与质量

- 纳入与排除条件，以及排除发生在哪个阶段：
- 重复行、重复参与者、重复试次或重复时间戳如何定义：
- 缺失值的编码（空白、NA、-999、特殊字符串等）：
- 目标/预测特征缺失时的处理依据：
- 离群值和不可能值的定义、来源依据、处理方式：
- 是否需要量表反向计分、量表合成或有临床/专业阈值：
- 数值的单位是否一致；是否需要换算：
- 是否有正负值、零值、比率尺度或带符号目标：

## 研究设计与划分

- 真正的独立抽样单位：
- 是否配对、重复测量、嵌套或交叉结构：
- 新样本来自现有参与者，还是来自未见过的新参与者/机构/时间段：
- 期望的外部验证或留出方式；测试数据是否必须保持未触碰：
- 分类时每个独立单位是否都包含所有类别：
- 预测未来时允许的训练截止点与时间间隔：
- 有多少独立参与者/组、多少次观测、每组观测数范围：

## 最终统计与交付

- 需要估计哪些差异、关联、风险或模型比较：
- 哪些分析属于确认性、哪些属于探索性：
- 计划比较的家族/终点/亚组/模型数量：
- 需要给出什么效应量和置信区间；研究领域是否有规定：
- 缺失数据的分析策略依据：
- 主要结论应如何用非专业语言表达：
- 预期交付文件、保存目录、操作系统以及主试能运行的 Python 命令：
